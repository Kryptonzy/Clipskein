# ClipNest feature reference

A local-first macOS clipboard and screenshot memory. ClipNest watches the system clipboard, stores copied text, images, and file references on the Mac, runs OCR with Apple's Vision framework, and searches everything from one window.

This is the detailed inventory of implemented behavior. For setup, requirements, and known limitations, start with the [README](../README.md). A feature being implemented does not imply validation on every macOS version or third-party application.

## Included

- Text, image, and multi-file clipboard history
- Searchable file-reference groups that paste back into Finder and upload fields, with coalesced off-main availability checks, explicit checking/missing states, manual recovery refresh, and no hidden duplication of file contents—even for slow cloud or network paths
- In-place repair for moved or renamed file references, preserving group order, titles, aliases, tags, Pinboards, pins, usage history, and concealment while rejecting ambiguous duplicates
- Native cross-app drag and drop for text, rich text, images, and true multi-file groups, with all-or-nothing missing-file checks and concealed-item protection
- Native Quick Look for referenced files from both the main inspector and Quick Picker
- Non-destructive text and OCR editing that creates or reuses a separate searchable clip while preserving the original history
- Validated rich-text preservation for formatted text from native apps and browser HTML selections, stored as restrictive sidecar files with an explicit paste-without-formatting action; HTML conversion is size-bounded, rejects external or embedded resources, and is accepted only when its visible text exactly matches the plain-text representation
- High-fidelity URL copy and drag: standalone safe HTTP/HTTPS links publish native `public.url` alongside plain text and validated RTF, so browsers and rich destinations receive a real link while credential-bearing or non-link text stays ordinary text
- Local Markdown detection with a structured preview/source toggle and paste-as-plain-text actions in both the detail view and Quick Picker
- Global duplicate suppression that refreshes reused clips without losing titles, pins, or usage signals
- On-device screenshot OCR via Vision with automatic language detection and a zero-configuration system-language mode, plus an optional persistent, reorderable priority list of up to six device-supported languages for mixed-language workflows; supported fallbacks cover accented Latin text plus Simplified/Traditional Chinese, Japanese, and Korean, and Settings can requeue every failed/no-text historical screenshot at once under the new priority with live results and safe cancellation that keeps completed work, restores unfinished states, skips missing originals honestly, and prevents cancelled waiters from consuming later analysis slots
- EXIF-aware JPEG/HEIC recognition and orientation-safe PNG normalization, so rotated phone exports stay upright in previews, OCR, search, and future relaunches
- Burst-safe OCR scheduling with a visible queue, bounded concurrency, lock-time cancellation, and off-main encrypted-image recovery after unlock or relaunch
- On-device QR and barcode recognition for screenshots and images, with searchable encrypted payloads, safe web-link opening, and direct copy or paste actions
- Opt-in screenshot inbox that watches the macOS screenshot folder, ignores existing files, waits for writes to finish, deduplicates imports, and makes new screenshots searchable with local OCR
- Confirmed one-click backfill of up to the 500 most recent likely screenshots from the exact folder configured by macOS, with no recursive photo-library scan, encrypted copies, local OCR, duplicate skipping, live progress, cancellation, resumable remaining work, and targeted retry of only unreadable or failed files; recovery paths stay in session memory and are destroyed on lock or dismissal
- File-identity screenshot tracking that detects genuinely rewritten screenshots at a reused path without reordering history when only metadata changed
- First-run setup can enable Screenshot Inbox in place and shows its active, failed, retrying, and recovered states
- Actionable screenshot-inbox recovery with automatic retries, a visible retry-now control, in-progress state, and explicit confirmation when folder access returns
- Background screenshot-folder discovery, polling, image decoding, PNG normalization, hashing, and AES-GCM persistence to keep launch and foreground interaction responsive
- Screenshot Inbox write failures never create phantom history or permanently consume the candidate; the unchanged file is retried automatically on the next successful poll
- Background clipboard-image processing: TIFF normalization, SHA-256 fingerprinting, AES-GCM attachment encryption, and atomic disk writes run through a memory-bounded serial queue with capture-time ordering, text fallback for malformed payloads, and lock-screen cancellation; reading the system pasteboard still takes place on the main thread
- Cold-cache image thumbnails plus full-resolution copy, paste, and drag payloads load and decrypt off the main thread, show immediate progress, and cancel without repopulating sensitive memory or touching the clipboard when the user dismisses Quick Picker or the Mac locks
- Image copies and drags publish the exact stored PNG or GIF alongside a TIFF compatibility fallback; destinations that accept the original GIF can retain its animation, while those choosing TIFF receive a static image. GIF bytes remain intact through encrypted storage, backup restore, export, and the original-format copy and drag representations
- GIF OCR reads only the first frame. With secret protection enabled, multi-frame GIFs stay concealed because later frames have not been analyzed; single-frame GIFs are treated as static images rather than labeled animated
- Persisted image dimensions and byte sizes are extracted without decoding pixels, shown in both the library and Quick Picker without reopening encrypted attachments, and make exact dimensions such as `1920x1080` searchable; older history is upgraded lazily off-main when an image is first used
- Explicit PNG or original GIF export from the main inspector or Quick Picker, with background decryption, restrictive `0600` file permissions, atomic destination writes, protected-store destination rejection, and lock/quit cancellation that removes plaintext staging files
- Local OCR-table detection with one-click Markdown, JSON, and escaped HTML export from both the detail view and Quick Picker
- Ranked, typo-tolerant multi-term search across copied text, recognized text, and source applications
- Stable source-app identity records each captured app's validated bundle identifier, keeps it through duplicate refreshes, edits, file-reference repairs, encrypted drafts, and backups, makes the identifier searchable, and overlays the installed app's real icon in both library and Quick Picker rows while old history falls back safely; both the library and Quick Picker filter menus group renamed app variants by that identity and expose the eight most-used sources with live counts, native icons, combinable one-click filters, active-state feedback, and one-step clearing
